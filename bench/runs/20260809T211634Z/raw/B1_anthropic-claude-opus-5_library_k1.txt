```
* AD8092 Non-Inverting Amplifier, Av = +5 V/V, +/-5 V supplies
* Output measured at node OUT, input driven at node IN

.lib ADI.lib

* ---- Supplies ----
VCC VCC 0 DC 5
VEE VEE 0 DC -5

* ---- Input source: 100 mV amplitude sine at 1 MHz ----
VIN IN 0 DC 0 AC 1 SINE(0 0.1 1MEG)

* ---- Amplifier: X(+IN -IN V+ V- OUT) ----
XU1 IN FB VCC VEE OUT AD8092

* ---- Feedback network: gain = 1 + Rf/Rg = 1 + 4k/1k = 5 ----
RF OUT FB 4k
RG FB 0 1k

* ---- Output load ----
RL OUT 0 1k

* ---- Analysis ----
.tran 0 5u 0 100p

* ---- Measurements ----
.meas TRAN vopp PP V(OUT) FROM 2u TO 5u
.meas TRAN vipp PP V(IN)  FROM 2u TO 5u
.meas TRAN gain PARAM vopp/vipp
.meas TRAN gain_db PARAM 20*log10(vopp/vipp)

.options plotwinsize=0 numdgt=7
.end
```
