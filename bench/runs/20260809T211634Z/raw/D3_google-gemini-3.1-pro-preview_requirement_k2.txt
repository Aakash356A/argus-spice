* AD8237 Instrumentation Amplifier Circuit

* Power Supply (Single 5V)
VCC VCC 0 5

* Reference Voltage (Mid-supply = 2.5V)
VREF REF 0 2.5

* Input Common-Mode Bias (2.5V)
VCM INM 0 2.5

* Differential Input Signal (20 mV amplitude, 1 kHz sine)
* The primary input node is IN. The sine source is applied differentially between IN and INM.
VIN IN INM SINE(0 20m 1k)

* Gain Setting Resistors
* AD8237 gain formula: G = 1 + R2/R1
* For G = 10 V/V, R2/R1 = 9. Using 90k and 10k.
R1 FB REF 10k
R2 OUT FB 90k

* AD8237 Subcircuit Instantiation
* Standard MSOP-8 pinout order: 1:-IN, 2:+IN, 3:BW, 4:-VS, 5:REF, 6:FB, 7:OUT, 8:+VS
* BW pin is tied to VCC for high bandwidth mode.
X1 INM IN VCC 0 REF FB OUT VCC AD8237

* Transient Analysis (5 milliseconds to capture 5 cycles at 1 kHz)
.tran 0 5m 0 1u

* Measurements to verify the gain_db target
* Measure peak-to-peak voltages over the last 3 cycles to ensure settling
.meas tran vout_pp PP V(OUT) FROM 2m TO 5m
.meas tran vin_pp PP V(IN,INM) FROM 2m TO 5m
.meas tran gain param vout_pp/vin_pp
.meas tran gain_db param 20*log10(gain)

.end
