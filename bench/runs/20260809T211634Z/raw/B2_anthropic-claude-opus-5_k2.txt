* Signal source: 50 mV amplitude, 1 kHz sine

VCC VCC 0 DC 15

* Gain setting network:  Av = -R2/R1 = -10k/1k = -10 V/V (20 dB)

* Op amp: non-inverting input grounded, inverting input is summing node
XU1 0 N1 VCC VEE OUT ADA4177

* Light load
RL OUT 0 10k

* -------------------------------------------------------------------
* ADA4177 behavioral macromodel
* Pin order: 1=+IN  2=-IN  3=V+  4=V-  5=OUT
* Aol ~ 1e6 (120 dB), GBW ~ 3.5 MHz, rail-to-rail limited output
* -------------------------------------------------------------------
.subckt ADA4177 1 2 3 4 5
RIN 1 2 1T
CIN 1 2 5p

IB1 1 0 0.5n

* -------------------------------------------------------------------
.tran 0 5m 0 1u

.meas TRAN vin_pp  PP V(IN)  FROM=1m TO=5m
