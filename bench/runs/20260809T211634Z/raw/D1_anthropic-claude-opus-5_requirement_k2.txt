VCC   VCC 0  DC 5

R2    REF 0   16.5k
CBYP  REF 0   100n           ; reference bypass

*-------------------- Comparator ------------------
* Pin order: +IN  -IN  V+  V-  OUT
XU1   REF IN VCC 0 OUT LT1720

*-------------------- Output pull-up / load -------

.lib LTC.lib

.tran 0 500u 0 100n
