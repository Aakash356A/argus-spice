* ADP7118 Low-Dropout Regulator: 3.3 V IN -> 1.8 V OUT at 50 mA
* -----------------------------------------------------------------
* Vendor macro-model library (ADP7102/ADP7104/ADP7118 family)
.lib ADP7102.lib

* ---------------- Source ----------------
V1 IN 0 DC 3.3
* small source/trace impedance
RS IN INX 0.05

* ---------------- Input decoupling ----------------
C1 IN 0 1u
CBULK IN 0 10u

* ---------------- LDO -----------------------------
* Pin order: VIN  VOUT  GND  EN  ADJ(feedback)
XU1 IN OUT 0 IN ADJ ADP7118

* Output setting divider (VREF = 0.5 V):
* VOUT = 0.5 * (1 + R1/R2) = 0.5 * (1 + 26k/10k) = 1.8 V
R1 OUT ADJ 26k
R2 ADJ 0 10k
* Optional feed-forward cap for transient response
CFF OUT ADJ 10p

* ---------------- Output decoupling ----------------
C2 OUT 0 1u
RESR OUT OUTX 0.01
C3 OUTX 0 1u

* ---------------- Load: 1.8 V / 36 ohm = 50 mA -----
RL OUT 0 36

* ---------------- Analysis -------------------------
.tran 0 5m 0 1u uic
.meas TRAN vout_dc AVG V(OUT) FROM 4m TO 5m
.meas TRAN iload AVG I(RL) FROM 4m TO 5m
.meas TRAN vdrop PARAM 3.3-1.8

.options plotwinsize=0 gmin=1e-12 abstol=1e-12 reltol=1e-4
.end
