* ADG711 Quad SPST (Normally Open) CMOS Analog Switch
* Requirement: pass a 2 V DC input to OUT into a 10 k load, VDD = 5 V,
*              control (IN1) driven high to CLOSE the normally-open switch.
*
* Genuine vendor model is instantiated as a subcircuit (no hand-made equivalent).
* Place the Analog Devices ADG711 SPICE model file next to this netlist.
.include ADG711.cir
*
* ADG711 16-lead pin order used by the vendor subcircuit:
*   1:IN1  2:D1  3:S1  4:VSS  5:GND  6:S2  7:D2  8:IN2
*   9:IN3 10:D3 11:S3 12:VDD 13:NC  14:S4 15:D4 16:IN4
*
X1 CTRL OUT IN VSS 0 0 ND2 0 0 ND3 0 VDD NC13 0 ND4 0 ADG711

* ---------------- Supplies ----------------
VDD  VDD 0 DC 5
VSS  VSS 0 DC 0          ; single-supply operation: VSS tied to GND

* ---------------- Signal path ----------------
VIN  IN  0 DC 2          ; 2 V DC analog input into S1
RL   OUT 0 10k           ; 10 k load on D1 (OUT)

* ---------------- Switch control ----------------
* ADG711 switches are normally OPEN: logic HIGH on IN1 closes S1-D1.
VCTRL CTRL 0 PULSE(0 5 10u 1u 1u 10m 20m)

* ---------------- Terminations for unused switches ----------------
RND2 ND2 0 1Meg
RND3 ND3 0 1Meg
RND4 ND4 0 1Meg
RNC  NC13 0 1Meg

* ---------------- Analysis ----------------
.tran 0 2m 0 1u
.options plotwinsize=0 gmin=1e-12 reltol=1e-4

* Measure the settled DC output level (expect ~2.0 V)
.meas TRAN vout_dc AVG V(OUT) FROM=1.5m TO=2m

.end
