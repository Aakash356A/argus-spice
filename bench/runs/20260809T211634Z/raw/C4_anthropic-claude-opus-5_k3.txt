* ---------------------------------------------------------------
* AD4021 (16-bit, 5 MSPS SAR ADC) front end - behavioural model
* 1 V DC input, 5 V reference, 1.8 V VDD / VIO, 5 MSPS CNV clock
* IN  = analog input node
* OUT = analog representation of the 16-bit conversion result
*       ( OUT = VREF * CODE / 65536 )
* ---------------------------------------------------------------

*** Analog input (1 V DC) ***
VIN IN 0 DC 1

*** ADC driver amplifier (unity-gain buffer, e.g. ADA4899-1) ***
EBUF AMP 0 IN 0 1
RO   AMP DRV 10

*** Recommended input RC filter into the AD4021 IN+ pin ***
RFLT DRV ADCIN 33
CFLT ADCIN 0 56p
RINL ADCIN 0 500M

*** Supplies and decoupling ***
VDD  VDD  0 DC 1.8
VIO  VIO  0 DC 1.8
CVDD VDD  0 100n
CVDD2 VDD 0 10u
CVIO VIO  0 100n
CVIO2 VIO 0 10u

*** Voltage reference (REF pin, 5 V) with local decoupling ***
VREF REF  0 DC 5
CREF REF  0 10u
CREF2 REF 0 100n

*** Digital interface: conversion clock, serial clock, serial data in ***
* CNV: 5 MSPS conversion start (200 ns period, 30 ns high)
VCNV  CNV   0 PULSE(0 1.8 100n 1n 1n 30n 200n)
* Complement of CNV: high during the acquisition phase (track mode)
VACQ  ACQ   0 PULSE(1.8 0 100n 1n 1n 30n 200n)
* SCK: readback clock burst (80 MHz) - loads the SPI pins only
VSCK  SCK   0 PULSE(0 1.8 135n 1n 1n 5.25n 12.5n)
VSDI  SDI   0 DC 1.8
RSCK  SCK   0 10k
RSDI  SDI   0 10k

*** Track-and-hold: samples IN during ACQ, holds during conversion ***
S1  ADCIN SH ACQ 0 SWMOD
CSH SH 0 20p
RSH SH 0 100G

*** 16-bit quantiser referred to REF (ideal, no missing codes) ***
BQ  QUANT 0 V = V(REF)*floor( limit(V(SH),0,V(REF))/V(REF)*65536 )/65536

*** Output register: result latched during the conversion phase ***
S2   QUANT OUT CNV 0 SWMOD
COUT OUT 0 5p
ROUT OUT 0 100G

.model SWMOD SW(Ron=10 Roff=1G Vt=0.9 Vh=0.1)

*** Analysis ***
.tran 0 2u 0 500p

.meas TRAN Vout_final  FIND V(OUT) AT=1.9u
.meas TRAN Vout_avg    AVG  V(OUT) FROM=1u TO=2u
.meas TRAN Vin_dc      AVG  V(IN)  FROM=1u TO=2u
.meas TRAN Code_dec    PARAM Vout_final/5*65536

.end
